# Локализация и награды

Базовый язык — русский. Все 59 конфигов предметов имеют русское отображаемое имя; технические `_name`/ID сохранены для совместимости инвентаря и сохранений.

Словари находятся в `Assets/Resources/Localization`: Russian, English, German, Spanish, Italian, French, Portuguese, Turkish, Indonesian. Формат прежний: `items` с полями `key` и `value`. Старые ключи достижений сохранены. Для остальных текстов ключом служит русская исходная строка, для динамических надписей — шаблон с `{0}`, `{1}` и т. д.

`LocalizationService` загружает русский словарь как резервный, затем выбранный язык. Кнопка языка в настройках переключает девять языков по кругу; выбор сохраняется в `PlayerPrefs` (`Localization.Language`).

`LocalizedTextScope` подключает локализацию текста префаба при открытии. `LocalizedTextRenderer` использует штатный `ITextPreprocessor` TextMeshPro: исходный `TMP_Text.text` остаётся прежним, перевод применяется при отображении. Это сохраняет логику интерфейса, которая читает исходные строки и числа. Поддерживаются точные строки, шаблоны счётчиков и составные надписи; различия пробелов при сериализации Unity учитываются. Динамически созданные TMP-компоненты дополнительно подключаются через событие обновления текста. Для старых `UnityEngine.UI.Text` используется `LocalizedLegacyText`. Rubik подключён как резервный шрифт для отсутствующих символов.

Переводы подготовлены машинным переводом; основные игровые термины дополнительно исправлены в `localization_overrides.py`. Это рабочие переводы, а не профессиональная языковая вычитка. В игре обращения к сервисам перевода отсутствуют.

## Добавление текстов

1. Используйте русский исходный текст в UI и отображаемых полях конфигов.
2. Запустите `py -3 Documentation/localize_catalog.py` (требуется PyYAML). Список источников обновится в `localization-sources.json`.
3. Заполните новые ключи во всех языковых JSON. Опциональный `translate_catalog.py` отправляет новые строки в Google Translate и создаёт машинные переводы; `localization_overrides.py` применяет проверенную игровую терминологию.
4. Для новых UI-префабов добавьте `LocalizedTextScope` на корень либо выполните `MineArena/Localization/Prepare UI` в Unity.
5. Выполните `MineArena/Validation/Localization and Rewards` в Edit Mode без загруженного игрового сохранения.

## Исправления наград

- Полученные ежедневные карточки затемняются целиком, включая иконку и текст. Последний день оставляет весь цикл затемнённым; следующий доступный цикл снимает затемнение. Состояние завершённого цикла сохраняется в прогрессе.
- Указатель колеса — треугольная UI-геометрия, независимая от шрифта. Он закреплён над колесом и отклоняется при прохождении секторов.
- При прохождении сектора воспроизводится существующий эффект `UIClick` через `AudioManager`, с учётом настроек громкости эффектов.
- До расходования вращения проверяется доступность инвентаря и конфигураций наград. Завершение защищено от повторного начисления; при отключении окна во время анимации выбранная награда начисляется. Замена уникальных предметов и компенсация 25 алмазами сохранены.

Проверки используют временную preview-сцену и отдельный `PlayerProgress`; пользовательское сохранение не загружается. Отчёт: `validate-localization-rewards.txt`. Превью: `UI/Daily-Claimed.png`, `UI/Wheel-German.png`, `UI/Settings-Turkish.png`.
