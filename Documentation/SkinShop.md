# Магазин скинов

В `SampleScene` добавлено место `BuildingZoneSkinShop`: **(10, 0.49, 9)**, южная площадка базы рядом с мастерской. Строительство стоит **24 доски + 16 камня**. После постройки вход в зону открывает магазин. Здание использует обычные сохранения и анимацию строительства, имеет один уровень.

Модель: `Assets/Prefabs/Buildings/SkinShop/SkinShop.prefab`. Каменное основание, дубовые стены, ступенчатая крыша, полосатый навес, эмблема рубашки и два манекена. Место постройки сохранено в сцене и в отдельном префабе.

Каталог: `Assets/Resources/UI/SkinCatalog.asset`. Включает базовый образ и восемь имеющихся текстур. Поля `Id` сохраняются в прогрессе: после выпуска не переименовывать существующие ID.

| Образ | Получение |
| --- | --- |
| Путешественница | Доступна сразу |
| Странник | 20 золотой руды |
| Солнечный утёнок | Полный цикл ежедневных подарков |
| Каменный | 40 золотой руды |
| Алхимик | Получение награды задания со StableId 0 |
| Капитан | Получение награды задания со StableId 1 |
| Тень | IAP `skin_shadow` |
| Пилот | Оффер `pilot_style_bundle`: скин + 30 золотой руды |
| Лесной | 90 золотой руды |

Квестовые скины выдаются автоматически при получении награды. Для уже выполненных квестов доступна кнопка получения в магазине. Для других событий используйте `SkinService.GrantReward(rewardId)` из подтверждённого обработчика награды; `RewardId` и `Source = Reward` задаются в каталоге.

Скины меняют текстуру тела через `MaterialPropertyBlock`. Броня, оружие, здоровье, урон и скорость не изменяются. Владение и выбранный образ хранятся в `PlayerProgress.CosmeticsProgress`, отдельно от расходуемого инвентаря, и не теряются при его очистке. Старые сохранения получают базовый образ. Выбранный ID передаётся через существующую сетевую кастомизацию.

## IAP и офферы

Маппинг находится в `Assets/Resources/UI/YandexPurchaseCatalog.asset`: `SkinIds` может содержать несколько скинов; `Item`/`Amount` добавляют валюту или ресурс в тот же набор. `ProductId` должен совпадать с каталогом скинов и ID товара в кабинете платформы. Наборы показываются в магазине скинов вместе с их составом.

**Реальные товары ещё нужно создать/настроить в кабинете Яндекс Игр** с указанными ID либо заменить ID в обоих каталогах. Цены берутся только из ответа платформы. Если товар недоступен, кнопка покупки отключена и показывает «Скоро в продаже». На других платформах новая платёжная интеграция не добавлялась.

Выдача выполняется существующим обработчиком подтверждённой покупки; receipt и награды сохраняются до consume. Повторная обработка receipt не выдаёт награду повторно. Поддержано восстановление покупок. Реальную оплату и восстановление необходимо проверить в sandbox платформы после настройки товаров.

## Проверка

Unity 2022.3: компиляция, загрузка копии сохранённой сцены, ровность участка и отсутствие пересечений, сохранение/загрузка владения и выбора, недостаток валюты, повторная покупка, ограничения способов получения, квестовая и ежедневная выдача, изменение только текстуры тела, регистрация окна и отображение каталога.

Отчёт: `Documentation/skin-shop-validation.txt`. Изображения: `Documentation/UI/SkinShopWindow.png`, `Documentation/UI/SkinShop-building.png`.

Редакторская команда `MineArena/Cosmetics/Build Skin Shop Assets` пересобирает модель, превью, окно, конфиг здания и запускает проверки. Существующий каталог скинов сохраняется. Команда добавляет место в открытую сцену, сохраняя несохранённые правки пользователя; на диске обновляется только экземпляр места постройки.
