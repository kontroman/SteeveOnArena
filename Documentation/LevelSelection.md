# Окно выбора уровня

Рабочий префаб: `Assets/DevotionSDK/Prefabs/UI/SelectLevelWindow.prefab`.
Его GUID и fileID компонента сохранены: существующий UIManager открывает обновлённое окно без перенастройки сцен.

## Стиль

Светлый песчаный фон `#F3E7CF`, карточки `#FAF1DE`, тёмный текст `#514737`, оливковый акцент `#819454`.
Пиксельные рамки имеют срезы 9-slice, Point-фильтрацию и прозрачные ступенчатые углы.
Внешняя граница окна усилена тёмным Outline толщиной 3 px и Shadow со смещением (8, −10). Цвет, прозрачность и смещение можно менять на `ExpeditionPanel` в префабе; эффекты масштабируются вместе с окном.
Заголовки используют существующий Minecraft Rus, подписи — Rubik.
Панель рассчитана на горизонтальный экран, автоматически уменьшается с сохранением пропорций. В портретном режиме она также помещается, но отдельной мобильной компоновки нет.

## Состав

- `Assets/Art/UI/Expedition/`: панорама, пиксельный замок и шесть PNG для панелей, карточек, выделения, кнопок и ресурсов.
- `Assets/Prefabs/Windows/SelectLevelWindow/LevelCard.prefab`: карточка уровня.
- `Assets/Prefabs/Windows/SelectLevelWindow/ResourceChip.prefab`: иконка ресурса, имя и количество награды.
- В основном префабе сохранена настоящая иерархия UI с примером текущих данных; её можно редактировать в Prefab Mode.
- Список уровней и подробности имеют отдельные ScrollRect. Кнопка старта и причина блокировки остаются видимыми.

## Добавление уровней

1. Создайте `LevelConfig`, задайте Display Name, Description, Level Icon, Difficulty и Level Prefab.
2. Заполните Available Resources и Reward Resources. Количество отображается только для награды; добыча зависит от игрового процесса.
3. Добавьте конфиг в конец списка `Assets/ScriptableObjects/GameConfig.asset → Levels`.

В GameConfig подключены четыре уровня: Поселение → Заброшенная шахта → Песчаный карьер → Лесная чаща. Два дополнительных уровня добавлены в конец, чтобы сохранить индексы существующего прогресса.
Порядок в списке определяет последовательное открытие; сохранения хранят индекс, поэтому перестановка уже выпущенных уровней изменит смысл существующего прогресса.
Первый уровень открыт по умолчанию. Выход через портал открывает и сохраняет следующий уровень. Закрытую карточку можно выбрать и изучить, но запуск заблокирован и в UI, и в обработчике загрузки.
Окно обновляется при каждом открытии; пустые списки и отсутствующий Level Prefab обрабатываются без запуска.
Имена ресурсов берутся из ItemConfig.DisplayName; необязательное поле Display Name можно заполнить у нового предмета. Внутренний Name остаётся идентификатором инвентаря.
Ресурсы с BlockStyleIcon используют существующий `Assets/Prefabs/Windows/ResourceIcon.prefab` с тремя гранями куба; остальные предметы сохраняют обычную иконку. Закрытые карточки и превью затемнены, просмотр остаётся доступен.

Оформление v2: новая простая пиксельная панорама `expedition-landscape-v2.png`, созданная встроенным image_gen (промпт: `Documentation/level-selection-art-prompt-v2.txt`), и бесшовная бледная кирпичная текстура `beige-brick.png`, нарисованная кодом сборщика. Текстура повторяется без растягивания; интенсивность отдельных слоёв регулируется цветом Image `PaleBrickTexture`.

## Инструменты редактора

- `MineArena → UI → Rebuild Beige Level Selection`: пересобрать окно и дочерние префабы (перезаписывает ручные правки их верстки).
- `MineArena → UI → Render Level Selection Preview`: сохранить снимок в `Documentation/level-selection.png`.
- `MineArena → UI → Validate Level Selection`: проверить ссылки, доступность, пустые данные, отсутствие дубликатов и прокрутку 40 уровней; результат — `Documentation/level-selection-validation.txt`.

Валидация редактора не заменяет прохождение в Play Mode: переход в GameplayScene, сбор ресурсов и выход через портал нужно проверить в игровом запуске.

## Графика

Иконки всех четырёх локаций обновлены: `Assets/Art/UI/Expedition/Levels/level-{village,mine,quarry,forest}.png`. Созданы отдельными вызовами встроенного image_gen; промпты — `Documentation/level-icons-prompts.txt`. Unity использует размер до 256 px и Point-фильтрацию. Ссылки записаны в LevelConfig, поэтому и карточки, и подробное превью показывают новые иконки. Повторная установка: `MineArena → UI → Install Pixel Level Icons`.

Панорама создана встроенным image_gen; рамки нарисованы кодом сборщика в принятом в проекте формате 9-slice. Существующие иконки арен и предметов переиспользованы. Полный промпт панорамы сохранён в `Documentation/level-selection-art-prompt.txt`.
